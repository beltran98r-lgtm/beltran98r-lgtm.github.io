# StaffSync

StaffSync is a mobile-friendly employee scheduling prototype for availability, staffing coverage, callouts, sick calls, and instant shift swaps.

## Live site

https://beltran98r-lgtm.github.io/

## Employee QR destination

https://beltran98r-lgtm.github.io/?view=availability

The QR code on the homepage automatically points employees to the availability workflow when the site is opened from its live GitHub Pages address.

## Prototype note

This GitHub Pages version is a front-end demo. Data is stored in each browser's localStorage, so information entered on one device is not yet shared across employee and manager devices. A future production version can add a shared database, employee authentication, notifications, and manager approval rules.
